本指南围绕研究生普遍需要的九类科研能力整理26项通用资料。补充中文基础材料和可复现分析资料，帮助学生根据当前问题找到合适的读物，并把学习用于真实研究。

## 01 使用方法
{: #chapter_01 }

起步：建立科研、阅读和记录习惯。常用：在设计、分析、写作或汇报时反复参考。按需：到投稿、参会、毕业或职业选择时再读。每次选1至2项即可，已有基础可直接用练习复核。

建议先接触R01、[R02](#resource_R02)、[R04](#resource_R04)、R06和R09；Linux与R按实际基础补学。英文资料先看标题、规则和示例，再选与当前任务有关的段落。短文可以通读，教材与课程按指定范围选读。

每个板块给出一个配套练习，优先使用当前课题的数据、图或文字。练习可纳入现有周报或组内讨论，不单独增加汇报。选读建议和练习由本指南制定。

| **当前需要解决的问题** | **优先阅读的板块** |
| --- | --- |
| 课题主线或研究设计不清楚 | 02 科研思路与研究设计 |
| 读文献零散 缺少积累 | 03 文献阅读与管理 |
| 分析记录不完整 结果解释不足 | 04 统计与可复现研究；05 计算基础；06 科研作图 |
| 开始写论文或回应意见 | 07 科学写作与论文修改 |
| 准备正式汇报或参会 | 08 汇报会议与海报 |
| 需要改善合作或规划发展 | 09 同行评议与科研合作；10 研究生发展与职业规划 |

后面的资料可按当前任务跳转；英文原文名称保留，中文说明用于帮助选择。

## 02 科研思路与研究设计
{: #chapter_02 }

先明确要回答的科学问题，再决定数据、分析或实验。对干实验课题，同样要考虑对照、独立样本、混杂因素和验证方法。

| --- | --- |

| <span id="resource_R02"></span>**R02 [设计能回答问题的研究](https://www.ibiology.org/educators-resources/online-course/lets-experiment/lets-experiment-assessment-questions/)**<br><br>Let’s Experiment<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先读公开练习页中的研究问题、变量、对照、样本量和偏差相关问题；改写为自己的数据分析设计。<br><br>公开练习页可直接读；[完整课程](https://courses.ibiology.org/research-skills/experiment-design/)需账号，按需选学。 |

配套练习：画出“问题—假设—数据或实验—预期结果—其他解释”的关系，用它检查课题是否能得出可判断的结论。

## 03 文献阅读与管理
{: #chapter_03 }

阅读应留下可以比较和追溯的证据，逐渐形成对领域的判断。重点是建立自己的文献记录，并看懂不同研究为什么得出相同或不同的结论。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R04"></span>**R04 [建立持续的阅读习惯](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006467)**<br><br>Ten simple rules for developing good reading habits during graduate school and beyond<br><br>Lowe-Power Lab推荐｜英文｜起步 | 先看如何兼顾基础文献与新研究、使用文献管理工具，以及保留长期阅读记录。选择适合自己的持续阅读方式。 |
| <span id="resource_R05"></span>**R05 [把零散文献整理成综述](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003149)**<br><br>Ten Simple Rules for Writing a Literature Review<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先读主题与读者界定、反复检索、边读边记录和批判性比较。围绕一个具体问题整理5篇论文，比较证据及分歧。 |
| <span id="resource_R06"></span>**R06 [管理文献与参考文献](https://zotero-chinese.com/user-guide/)**<br><br>Zotero百科全书<br><br>中文社区维护｜中文｜起步 | 先读“添加条目”“笔记”“直接生成参考文献表”。完成一个课题文献夹，核对作者、年份、题名和DOI。<br><br>初次只用本地文献库与基本功能；插件、云同步和复杂配置按需使用。 |

配套练习：比较5篇论文的问题、证据和局限，写出一处共识或矛盾及其与课题的关系。

## 04 统计与可复现研究
{: #chapter_04 }

统计训练从研究设计和结果解释开始。对组学数据，尤其要区分独立生物学重复、技术重复，以及同一生物学样本中的大量测量。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R07"></span>**R07 [解释统计结果](https://www.graphpad.com/guides/prism/latest/statistics/stat_---_principles_of_statistics_-.htm)**<br><br>GraphPad Principles of Statistics<br><br>Lowe-Power Lab与Graim Lab推荐｜英文｜常用 | 先看SD与SEM、置信区间、P值解释和多重比较。结合一个自己的结果，说明独立样本、误差线和结论强度。<br><br>统计原理部分可公开阅读，无需购买或安装Prism。 |
| <span id="resource_R08"></span>**R08 [识别伪重复和异常显著性](https://arxiv.org/abs/1911.03509)**<br><br>If your P value looks too good to be true, it probably is: Communicating reproducibility and variability in cell biology<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先读样本量N、独立重复和细胞层面测量的区别。检查自己的数据中哪些观测来自同一样本，避免把它们全算成独立重复。<br><br>原文以细胞生物学为例；其他数据需先明确实验或抽样单位。 |
| <span id="resource_R09"></span>**R09 [留下可复查的数据与分析](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005510)**<br><br>Good enough practices in scientific computing<br><br>Graim Lab推荐｜英文｜起步 | 先读数据管理、项目组织和分析记录部分。整理一个小项目的原始数据、脚本、结果和README，让同学能够找到并复查关键步骤。<br><br>版本控制等进阶部分在需要协作时继续学习。 |

配套练习：让同学根据README重新生成一张图；记录其遇到的一个问题，并修正记录或脚本。

## 06 数据可视化与科研作图
{: #chapter_06 }

一张科研图首先要回答一个问题。制作前先写出想传达的结果，再选择图形、坐标和图注；也要检查图是否掩盖了数据中的重要差异。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R12"></span>**R12 [让图准确传达结果](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003833)**<br><br>Ten Simple Rules for Better Figures<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先读明确图的信息、完整图注、避免误导和减少无用装饰。检查坐标、单位、样本量、配色和图注是否支持正确理解。 |
| <span id="resource_R13"></span>**R13 [理解为什么必须看原始数据](https://www.research.autodesk.com/publications/same-stats-different-graphs/)**<br><br>Same Stats, Different Graphs<br><br>Lowe-Power Lab推荐｜英文 图示为主｜常用 | 先看具有相似统计量却形状不同的数据图。联系自己的结果，思考异常值、分布或分组结构是否被均值和相关系数掩盖。<br><br>只看图示与说明即可起步，模拟退火算法和代码按需阅读。 |

配套练习：改进一张已有图，保留修改前后版本；说明改动解决了哪一个信息表达问题。

## 07 科学写作与论文修改
{: #chapter_07 }

写作既是表达结果，也是检验思路。先建立故事主线和证据顺序，再修改段落和句子。不同材料分别用于开始写、搭结构、改善表达和回应评价。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R14"></span>**R14 [持续推进写作](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006379)**<br><br>Ten simple rules for scientists: Improving your writing productivity<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先看如何把写作变成可执行的小任务、建立固定写作习惯并获取反馈。选一节真实内容，先完成可讨论的初稿。 |
| <span id="resource_R15"></span>**R15 [建立论文结构](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005619)**<br><br>Ten simple rules for structuring papers<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先确定核心贡献，理解引言、结果、讨论之间的关系。为自己的项目写一页提纲，说明每一部分要回答什么问题。 |
| <span id="resource_R16"></span>**R16 [改善段落和句子](https://lowepowerlab.ucdavis.edu/assets/resources/science_of_writing.pdf)**<br><br>The Science of Scientific Writing<br><br>Lowe-Power Lab推荐｜英文 PDF｜常用 | 先选一组修改前后对照例子，学习信息顺序、句子重点和衔接。修改自己的一段文字，再请同学指出读者最容易困惑的地方。<br><br>PDF约16页，分段选读即可。 |

配套练习：围绕一个关键结果写一段文字，包含结论、证据和限制；请同学复述其主旨，检验表达是否清楚。

## 08 汇报会议与海报
{: #chapter_08 }

正式汇报要让听众记住科学问题和关键结论。摘要、口头报告、幻灯片和海报的形式不同，应分别学习它们的信息组织方式。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R18"></span>**R18 [讲清楚一个研究故事](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.0030077)**<br><br>Ten Simple Rules for Making Good Oral Presentations<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先读面向听众、明确核心信息、逻辑顺序和计时练习。准备一个3分钟报告，结束后让听众复述问题与结论。 |
| <span id="resource_R19"></span>**R19 [制作清楚的幻灯片](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1009554)**<br><br>Ten simple rules for effective presentation slides<br><br>Lowe-Power Lab推荐｜英文｜常用 | 先看一页的信息重点、视觉层次、文字与图的配合。将三张堆文字的页面改成有明确结论和支撑图的页面。 |
| <span id="resource_R20"></span>**R20 [写会议摘要](https://lowepowerlab.ucdavis.edu/assets/resources/Gadoury_abstract_advice.pdf)**<br><br>Why We Write Abstracts for APS Meetings—and How We Can Do It Better<br><br>Lowe-Power Lab推荐｜英文 1页PDF｜按需 | 先理解摘要的目的与读者。写一段包含问题、方法、主要结果和意义的摘要，让同行判断是否值得听取报告。<br><br>例子来自植物病理学会议，具体字数与格式按目标会议要求调整。 |
| <span id="resource_R21"></span>**R21 [制作科研海报](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.0030102)**<br><br>Ten Simple Rules for a Good Poster Presentation<br><br>PLOS开放获取补充｜英文｜按需 | 先读目的、核心信息、可读布局与现场交流。借用组内已有模板，突出一个主要发现，并准备一段简短讲解。<br><br>Lowe-Power的海报板块提供设计思路；这里补充一篇可直接阅读的短指南。 |

配套练习：用同一个结果分别写一个摘要、做三张幻灯片或做一页海报，按近期真实需要选择一种。

## 09 同行评议与科研合作
{: #chapter_09 }

学会评价他人的证据，也能改进自己的研究。良好的反馈应具体、可执行；团队中的主动沟通、合作与指导需要双方共同参与。

| **资料与来源** | **用途与起步建议** |
| --- | --- |
| <span id="resource_R22"></span>**R22 [学习怎样评议论文](https://lowepowerlab.ucdavis.edu/assets/resources/peer_review_allen.pdf)**<br><br>Peer-Reviewing Scientific Manuscripts<br><br>Lowe-Power Lab推荐｜英文 2页PDF｜按需 | 先阅读这份组会讲义的审稿步骤和关注点。选择一篇已公开论文，分别列出主要优点、关键证据缺口和可执行的修改建议。 |
| <span id="resource_R23"></span>**R23 [建立健康的研究团队](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006914)**<br><br>Ten simple rules towards healthier research labs<br><br>Lowe-Power Lab推荐｜英文｜导师学生共读 | 围绕指导、合作、工作预期与个人发展选读。各自提出一个影响研究推进的问题，再讨论团队可以怎样改善。<br><br>适合作为导生讨论材料，结合实验室现有制度使用。 |

配套练习：将一句笼统评价改写为“具体问题—影响—可行建议”，并说明哪些判断需要更多证据。
